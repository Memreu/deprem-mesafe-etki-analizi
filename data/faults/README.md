# Aktif fay izleri (Türkiye ve çevresi)

`gem_active_faults_turkey.geojson`, GEM Global Active Faults Database'in
(`gem_active_faults_harmonized.geojson`, commit `56816508`) 25–45.5°D, 34.5–42.5°K
kutusuyla kesişen 477 izinden oluşan alt kümesidir. Koordinatlar 5 ondalığa yuvarlanmış,
öznitelikler sadeleştirilmiştir.

- Kaynak: https://github.com/GEMScienceTools/gem-global-active-faults
- Atıf: Styron, R., Pagani, M. (2020). The GEM Global Active Faults Database.
  *Earthquake Spectra* 36(1_suppl), 160–180. doi:10.1177/8755293020944182
- Lisans: **CC BY-SA 4.0**. Bu dosya ve ondan türetilen veriler aynı lisansla paylaşılmalıdır
  (deponun kodu MIT lisanslıdır; bu klasördeki veri CC BY-SA 4.0'dır).

Eğim yönü: harmonize katmanda `dip_dir` alanı yoktur. İzlerin Aki–Richards sağ el kuralıyla
sayısallaştırıldığı varsayılır (fay, iz yönünün sağına doğru eğimlidir).
